AUTENTIKASI DAN KEAMANAN
Penting: proyek ini adalah website statis HTML/JS. Kredensial login yang ditanam di JavaScript dapat ditemukan oleh siapa pun yang memeriksa source. Gerbang ini hanya membatasi tampilan, BUKAN pengamanan database. Firestore Rules yang lama juga mengizinkan sejumlah operasi publik. Jangan gunakan untuk data sensitif/uang/akun nyata sebelum otorisasi dipindahkan ke Firebase Authentication + custom claims dan Cloud Functions/server tepercaya.

FIREBASE
Konfigurasi Firebase yang sudah ada dipertahankan. Upload firestore.rules dari paket ini ke Firebase Console > Firestore Database > Rules bila ingin mempertahankan aturan proyek saat ini. Periksa dan amankan rules sebelum produksi; jangan mengaktifkan mode publik untuk data privat.

DEPLOY
1. Ekstrak ZIP.
2. Upload seluruh isi folder ke hosting yang sama (Vercel/Netlify), jangan hanya index.html.
3. Pastikan app.js, style.css, firestore.rules, logo, dan dispatch-logo.jpg ikut terunggah.
4. Di Firebase Authentication > Settings > Authorized domains, tambahkan domain website.
5. Di Firebase Console > Authentication > Sign-in method, aktifkan Google.
6. Pastikan Firestore Database sudah dibuat.
